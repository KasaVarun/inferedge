Phase 9-B1 constraints:

schema_version=1
thinking_mode=disabled
context_limit is an integer in 1..4096
gguf_size_bytes is an integer in 1..2147483648
gguf_architecture is qwen3 or llama
quantization is one of Q4_K_M, Q5_K_M, Q8_0, F16, F32
gguf_file is a safe basename ending in .gguf
license_file is a required safe basename
notice_file is a safe basename, or the token none
chat_template_file is a safe basename
SHA-256 fields are 64 lowercase hex characters
file names reject /, \, %, ., .., absolute paths, and control characters

license_file and notice_file were added so the package allowlist is exact.
license_sha256 is a required lowercase 64-hex SHA-256 of license_file.
notice_file=none requires notice_sha256=none. A declared NOTICE file
requires a safe basename and a matching lowercase 64-hex SHA-256.

The GGUF SHA-256 covers embedded tokenizer metadata. There is no separate
tokenizer_sha256 field. Phase 9-B2 independently verifies tokenizer
behavior against the pinned official tokenizer oracle.

The reserved Qwen non-thinking template identity is qwen3-non-thinking-v1.txt.
Phase 9-B1 does not certify that template against an official tokenizer.
